# 铸力微信小程序

这是现有健身记录 Web 原型的微信小程序版本，已配置 AppID `wxcbad07e3fb2b6b8e`。训练数据使用微信本地存储，不需要服务器。

## 在微信开发者工具中运行

1. 打开微信开发者工具并登录拥有该 AppID 权限的微信账号。
2. 点击“导入项目”。
3. 项目目录选择：`/Users/zhaoxuezhi/Documents/demo/fitness-log-miniapp/miniapp`。
4. AppID 会自动读取为 `wxcbad07e3fb2b6b8e`，确认后点击“导入”。
5. 等待模拟器显示“铸力”首页。

## 在手机上预览

1. 在微信开发者工具顶部点击“预览”。
2. 等待工具生成二维码。
3. 使用已加入该小程序开发成员或体验成员的微信扫码。
4. 首次打开后即可添加训练项目、记录训练并查看数据统计。

如果扫码提示没有权限，需要在微信公众平台的小程序后台将该微信号加入开发成员或体验成员。

## 更新代码后重新编译

在本目录安装依赖后运行：

```bash
npm run dev:weapp
```

该命令会持续编译到 `dist/`，微信开发者工具将自动刷新。一次性生产构建使用：

```bash
npm run build:weapp
```

运行自动检查：

```bash
npm test
```
