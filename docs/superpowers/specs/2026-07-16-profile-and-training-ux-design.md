# 第二轮训练与个人中心优化设计

## 目标

解决以下问题：

1. 微信登录后个人中心长期显示默认昵称“微信用户”。
2. 时长、距离、次数等指标型训练项目没有完成操作。
3. 训练内容较多时，底部“完成训练”遮挡列表和“添加项目”。
4. “我的”页面菜单缺少点击反馈和后续承载结构。

## 范围

本轮实现：

- 用户主动填写并保存微信昵称，可选取微信头像。
- 指标型项目支持完成和撤销完成。
- “添加项目”与“完成训练”进入统一底部操作栏，列表内容不被遮挡。
- “我的”页面菜单可点击，并按轻量设置与复杂管理采用弹框或二级页面。
- 训练目标和单位偏好可修改并持久化。
- 自定义项目进入独立管理页面。
- 训练提醒展示能力说明。
- 数据与隐私进入独立说明页面。

本轮不实现：

- 后台自动读取真实微信昵称。
- 微信订阅消息发送、定时任务或系统级通知。
- 账户注销和云端数据删除。
- 英制数据的历史批量换算。

## 微信资料

微信登录只用于识别用户身份，不自动返回真实昵称。新用户仍以“微信用户”作为安全默认值。

当用户资料仍为默认值时，“我的”资料卡显示“完善资料”提示。点击资料卡打开资料编辑弹框：

- 昵称使用微信小程序昵称输入能力，由用户主动确认。
- 头像使用微信小程序头像选择能力，可选填。
- 昵称去除首尾空格后不能为空。
- 保存时显示进行中状态，成功后立即更新资料卡并写入云数据库。
- 头像先上传云存储，再将文件 ID 与昵称一起保存。
- 用户取消或拒绝头像选择不影响登录和昵称保存。
- 保存失败时保留输入内容并显示明确错误，不覆盖原资料。

资料已经完善后，用户仍可点击资料卡再次编辑。

## 训练项目完成状态

训练项目分为两种记录方式：

### 逐组型项目

包含组数和次数的项目继续使用每组右侧的“完成”按钮。至少一组完成后，该项目可写入本次训练记录。

### 指标型项目

时长、距离、次数或重量直接输入的项目，在输入区下方显示整宽项目级按钮：

- 默认文案为“完成本项目”。
- 至少填写一个大于零的指标后才允许完成。
- 完成后按钮变为蓝色状态“✓ 已完成”。
- 再次点击可撤销，方便修正数据。
- 修改已完成项目的指标不会自动撤销完成状态。

完成整场训练时，只统计已完成的组和已标记完成的指标型项目。未标记完成的指标输入保留在当前草稿，但不进入训练历史。

## 训练页底部操作

“添加项目”和“完成训练”从滚动内容中移出，放入同一个固定底部操作栏：

- 左侧为描边按钮“＋ 添加项目”。
- 右侧为主按钮“完成训练”。
- 操作栏位于原生 TabBar 上方，并适配底部安全区域。
- 滚动区底部留白至少覆盖操作栏高度，最后一个项目始终可以完整滚动到操作栏上方。
- 页面内容较少时不产生多余的大块空白。
- 弹出键盘时依赖微信小程序窗口调整，操作栏不覆盖当前输入框。

## “我的”页面信息架构

采用轻量设置弹框与复杂管理二级页面混合的方式。

### 训练目标

点击后打开底部弹框：

- 展示每周训练目标。
- 提供 1 至 7 次的快捷选择。
- 保存后立即更新本周目标进度并同步用户偏好。

### 单位偏好

点击后打开底部弹框：

- 重量单位选择 kg 或 lb。
- 距离单位选择 km 或 mi。
- 本轮只改变后续录入和展示单位，不批量重算历史原始数据。
- 保存后同步用户偏好。

### 自定义项目

点击后进入独立二级页面：

- 仅展示用户创建的自定义项目。
- 展示项目名称和指标组合。
- 支持新增、编辑和删除。
- 删除前二次确认。
- 删除项目库定义不影响已经保存的历史训练快照。
- 删除正在本次训练中使用的项目时，仅删除项目库定义，不自动移除训练草稿。

### 训练提醒

点击后显示说明弹框：

- 说明微信提醒需要用户订阅消息授权。
- 明确当前版本尚未启用提醒。
- 只提供“我知道了”，不展示不能生效的时间选择器。

### 数据与隐私

点击后进入独立二级页面，展示：

- 微信身份与数据隔离说明。
- 云端保存的数据类型：用户偏好、自定义项目、训练记录。
- 本地缓存与离线同步说明。
- 当前同步状态和最近登录时间。
- “退出登录”和“删除云端数据”作为后续能力说明，本轮不提供会改变数据的按钮。

## 数据结构与状态

- `CurrentExercise` 增加指标型项目级 `completed` 状态。
- reducer 增加项目完成切换 action。
- session 构建逻辑过滤未完成的指标型项目。
- 用户偏好扩展为可更新每周目标、重量单位和距离单位。
- 资料编辑复用现有 `updateProfile` 云端写入接口。
- 自定义项目管理复用 `exerciseLibrary`，新增编辑和删除 reducer action；云端删除能力使用软删除字段。

旧的本地训练草稿没有 `completed` 字段时按未完成处理，避免升级后把仅输入但未确认的数据误写入历史。

## 错误与空状态

- 昵称保存失败：弹框保留并展示错误，可再次提交。
- 自定义项目列表为空：展示引导文案和新增按钮。
- 项目完成时没有有效指标：Toast 提示“请先填写训练数据”。
- 完成训练时没有任何已完成内容：Toast 提示“请先完成一项记录”。
- 云端设置保存失败：保留原设置，并提示稍后重试。
- 离线状态：本地状态继续可用，沿用现有待同步机制。

## 验收标准

- 默认用户可从资料卡主动填写昵称，保存后个人中心立即显示新昵称，重新进入后仍存在。
- 指标型新增项目填写数据后可以完成、撤销完成，并按完成状态进入历史。
- 训练项目超过一屏时，最后一项和两个底部操作按钮均可触达且互不遮挡。
- “我的”五个入口均有明确点击反馈。
- 训练目标和单位偏好能够保存并刷新页面文案。
- 自定义项目管理页支持空状态、新增、编辑和删除。
- 训练提醒不承诺尚未实现的通知能力。
- 数据与隐私页准确说明保存范围和同步状态。
- reducer、session 构建、资料存储和 UI 合约测试通过。
- TypeScript 检查和微信小程序生产构建通过。
